# Automatické stanice SHMÚ — mená a polohy

Kódy staníc (ind_kli) z otvorených dát SHMÚ (opendata.shmu.sk, CC BY 4.0), mená z tabuľky aktuálneho počasia
na shmu.sk. Polohy: WMO OSCAR/Surface (https://oscar.wmo.int, verejný register staníc WMO) podľa indexu WMO alebo
mena (src oscar-wmo / oscar-name / oscar-prefix); kde OSCAR stanicu nemá, PRIBLIŽNÁ poloha obce z GeoNames
(CC BY 4.0, src geonames, approx: true — UI ju tak označí). Postavené 2026-10-08 skriptom
scripts/build-shmu-stations.mjs. Stanice: WMO 24, meno 40, prívlastok 4, obec 26.
